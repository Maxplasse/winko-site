# Winko · site vitrine

Prototype HTML/CSS du site Winko (FR/UK), intégré depuis Figma et structuré en Client-First pour être reconstruit dans Webflow.

Aperçu local : ouvrir `index.html` dans un navigateur, ou lancer `python3 -m http.server`.

Voir `CLAUDE.md` pour le contexte, les conventions et l'avancement, et `docs/assets.md` pour les images à réexporter.
